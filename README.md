# Final project

## Emotion Detector

This repository contains the final project for building an emotion detection application using Python, IBM Watson NLP, and Flask.

### Project tasks

- Create an emotion detection function.
- Format the emotion detection output.
- Package the application as `EmotionDetection`.
- Add and run unit tests.
- Deploy the application with Flask.
- Handle invalid and empty input.
- Run static code analysis.
